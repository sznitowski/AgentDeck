# Principles

1. A lost mobile socket does not imply a stopped remote process.
2. ProjectProfile, server identity, environment, and execution policy are explicit.
3. Domain contracts do not expose a specific SSH library or Flutter widgets.
4. Production safety must be enforced by server privileges as well as UI policy.
5. Prefer small dependencies, evidence-backed validation, and documented decisions.
6. KAMMEL is an external technical reference, not our source tree or brand.
