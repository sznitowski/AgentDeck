# KAMMEL technical reference

KAMMEL SSH is an external Android/Linux Flutter project: https://github.com/Jhongdlp/Kammel_ssh . AgentDeck is independent. KAMMEL may inform SSH/SFTP, terminal, tmux, sessions, Git, and UX research. Its Android foreground service is not an iOS background strategy. Do not copy its files, assets, brand, or structure without documenting exact component, rationale, license, source commit, dependencies, iOS compatibility, and explicit user approval. No KAMMEL code was copied in M0.
