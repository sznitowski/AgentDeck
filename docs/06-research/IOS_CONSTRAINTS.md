# iOS constraints

iOS may suspend an app after it backgrounds or the screen locks; an SSH socket cannot be treated as persistent. tmux can keep a Linux process alive, so the client reconnects, re-verifies the host, and reattaches. Network changes require reconciliation. Keychain stores secrets; Face ID/Touch ID can gate access. Files are accessed through the app sandbox and user-selected documents. Continuous agent alerts while the app is suspended require server observation and APNs, not a permanent local monitor. Validate on macOS/Xcode and device before promising behavior.

Sources: https://developer.apple.com/library/archive/documentation/NetworkingInternetWeb/Conceptual/NetworkingOverview/Platform-SpecificNetworkingTechnologies/Platform-SpecificNetworkingTechnologies.html and https://developer.apple.com/documentation/UserNotifications/setting-up-a-remote-notification-server .
