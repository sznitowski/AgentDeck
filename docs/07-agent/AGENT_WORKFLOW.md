# Agent workflow

READ → UNDERSTAND → PLAN → IMPLEMENT → TEST → VERIFY → DOCUMENT → HANDOFF.

Before code changes read root AGENTS.md, CURRENT_STAGE.md, CURRENT_CONTEXT.md, and ARCHITECTURE.md. For sensitive work read docs/04-security/. Check milestone scope and exit criteria, inspect Git state, make small changes, run relevant gates, and report what was actually verified. Update the stage and handoff. Never advance a milestone because code merely exists.
